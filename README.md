# Evidence-Grounded Mental Health AI Agent

## Overview

An evidence-grounded mental health knowledge and psychoeducation agent developed using Retrieval-Augmented Generation (RAG) and LangGraph.

The system retrieves information from a curated knowledge base of reliable mental health sources and uses a language model to generate evidence-based responses.

## Technologies

- Python
- Qwen2.5-1.5B-Instruct
- LangChain
- LangGraph
- ChromaDB
- Sentence Transformers
- Streamlit
- Retrieval-Augmented Generation (RAG)

## Key Features

- Evidence-based information retrieval
- Context-aware response generation
- Evidence validation
- Source references and citations
- Insufficient-evidence handling
- Human review mechanisms
- Automated testing and evaluation

## Architecture

The system follows a retrieval-augmented workflow:

1. User submits a question.
2. The system retrieves relevant evidence.
3. Retrieved information is assessed.
4. The language model generates a response.
5. The response is validated against available evidence.
6. References are provided where available.

## Research Focus

This project explores how retrieval, evidence validation, and human oversight can improve the reliability of AI-generated mental health information.

## Project Status

Developed as an academic project. The system includes implementation, testing, and evaluation components. Further improvements and evaluation remain ongoing.

## Responsible Use

This application is intended for mental health education and general information. It is not a diagnostic tool and does not replace professional mental health care.
